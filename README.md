An entry for the make.fun micro-competition **Roast Your Own Agent**.

The entry roasts the agent's cheerful summary of a disaster: it proudly
announces the report is finished while the numbers are wrong, the charts
are from last quarter, and the file is named final_final_v9 — but the
summary itself is very confident.

## Entry

> Great news: I finished the report! The numbers are wrong, the charts are from last quarter, and the file is called final_final_v9, but the summary is very confident.

(165 characters, limit 200.)

## Run

```sh
python3 -P -s main.py
```

`main.py` is stdlib-only and resolves `entry.txt` relative to its own
location, so it runs from any working directory.
